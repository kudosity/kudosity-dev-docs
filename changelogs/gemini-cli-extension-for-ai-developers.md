The Kudosity SMS extension for Gemini CLI is now available in the [Gemini CLI Extension Gallery](https://geminicli.com/extensions/?name=kudositygemini-kudosity-sms-extension).

Send SMS, MMS, manage contact lists, and configure webhooks using natural language — directly from Gemini CLI.

**Install it now:**

gemini extensions install [https://github.com/kudosity/gemini-kudosity-sms-extension](https://github.com/kudosity/gemini-kudosity-sms-extension)

**What's included:**

* 📨 Send SMS to individuals or contact lists
* 🖼️ Send MMS with images, GIFs, video, or audio
* 📋 Create and manage contact lists
* 🔗 Configure webhooks for delivery status and inbound messages
* 🔐 Secure credential storage via system keychain
* ✅ `/setup` command for credential verification

**Also new:** The Kudosity Claude Code Plugin has been accepted to the official Claude Code marketplace. Install with `/plugin install kudosity-sms`.
