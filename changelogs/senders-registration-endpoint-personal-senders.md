Added a new endpoint for sender registration:

`POST /v2/senders/registrations`

This endpoint allows developers to register personal senders for messaging use cases.

> ⚠️ **Important:**
> This endpoint is currently limited to personal sender registrations only. Support for business or other sender types is not included at this time.

👉 [View API Reference](https://developers.kudosity.com/reference/post_v2-senders-registrations)
