Our APIs can help you build apps, script interactions, and develop various types of integrations to enhance communication with customers. This page documents the REST resources available in Kudosity Cloud, including HTTP response codes and example requests and responses.

# API Endpoints

We have a few API endpoints to better serve our customers:

## [api.transmitsms.com](post_send-sms-json)

This is our transactional API with speedy throughputs and high-reliability. You can sign up for a developer account and get started using this API in [under two minutes using this API](/docs/getting-started).

## **[api.transmitmessage.com](post_v2-sms)**

This is our newest high-transaction API with high-volume throughputs and high-reliability, MMS, Webhooks, and More! The API is only available for select customers.
