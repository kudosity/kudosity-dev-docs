# Contributing

This repository is the git mirror of the Kudosity developer portal at
https://developers.kudosity.com/ — it stays in two-way sync with ReadMe,
so merges to the `v1.0` branch publish to the live portal.

## What you can contribute to

- **`docs/`** — guides and tutorials. PRs welcome: fixes, clarifications,
  broken links, better examples.
- **`custom_pages/`** — landing page content.

## What is generated (don't edit here)

- **`reference/`** and **`public-openapi.yaml`** — the API reference is
  generated from OpenAPI specs in an internal repository and uploaded to
  ReadMe on every spec merge. Changes made here will be overwritten by
  the next upload. If you spot an API reference error, please open an
  issue instead of a PR.

## Questions

Open an issue, or reach us via https://support.kudosity.com/
