> 🚧 Kudosity's RCS API is Currently in Beta.

We are rapidly building out our WhatsApp API-First Beta and would love for you to get on board. If you're interested in joining our WhatsApp Beta program or you have any questions about it, please reach out to us at: [https://help.kudosity.com/s/submit-ticket](https://help.kudosity.com/s/submit-ticket)

## Eligibility

* You're building with APIs — no UI needed (yet)
* You're looking to deliver verified WhatsApp Business messages
* You're cool with a bit of rough edge while we finalize things

## 🌍 Global Availability

WhatsApp Business messaging is available worldwide with 2+ billion users.\
Meta's WhatsApp Business API supports global delivery, so let us know your target markets — we'll help optimize your messaging strategy for maximum engagement.

## 🧪 API + Docs: Work in Progress

Our API and docs are evolving fast.\
We don't anticipate major breaking changes, but some pieces may still be in flux. If something doesn't behave as expected, tell us — your feedback helps us improve.
