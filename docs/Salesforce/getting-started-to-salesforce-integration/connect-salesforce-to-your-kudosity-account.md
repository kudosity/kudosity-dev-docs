1. Open the App Launcher (9-dot grid icon, top-left navigation bar) and search for Kudosity.
2. Click the Kudosity app result — you will be taken to the setup screen.
3. Navigate to your Kudosity account Settings and copy your API Key and API Secret.

<Callout icon="ℹ️">
  If there is no API Secret shown in your Kudosity account, click Update Profile at the bottom of the Settings screen to generate one.
</Callout>
