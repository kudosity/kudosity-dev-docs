You will need your API credential and set an API secret. The API secret can be anything you like, but we recommend generating a long random set of characters to be safe.

To get your API key and set your API secrete:

1. Log onto your account.
2. Access your SETTINGS.
3. Scroll down to the API settings.
4. Copy API key and update your API secret.
5. Click Update Profile to save your changes.
