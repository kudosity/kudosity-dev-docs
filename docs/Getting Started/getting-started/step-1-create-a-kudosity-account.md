## New User Registration

If you are a new user, you'll need to create a trial account. If you're an existing user, you can skip this step and move onto [Step 2: Get Your API Key and Secret](step-2-get-your-api-key).

1. Got to: [https://kudosity.com/developer-trial](https://kudosity.com/developer-trial?utm_source=website\&utm_medium=banner\&utm_campaign=developer-portal)
2. Fill in your account details.
3. Accept the terms and privacy policies and then click the Create Account 

You will receive a verification email. Click the verification link to sign into your account.
